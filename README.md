# Knowlina Information Site

This package is built with HTML, CSS, and JavaScript only.

## Open Locally

The simplest option is to open the `index.html` file in your browser.

To open it with a local server, run one of the following commands in this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## File Structure

- `index.html` - home page
- `styles.css` - all design and responsive styles
- `script.js` - mobile menu, FAQ, and animations
- `terms.html` - Terms and Conditions
- `copyright.html` - Copyright
- `assets/` - app screenshots

## Editing

You can update text in the HTML files, and colors and sizes from the variables at the beginning of `styles.css`.
